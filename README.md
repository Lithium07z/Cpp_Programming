# C++ 프로그래밍 실습

2022년 2학기 학부 C++ 프로그래밍 수업의 예제와 실습문제 풀이입니다. 기본 입출력부터 클래스, 메모리 관리, 연산자 오버로딩, 상속과 템플릿까지 주차별로 정리했습니다.

각 예제는 독립적인 학습 코드입니다. 실행 가능한 프로그램뿐 아니라 문제 설명, 답안, 주석 처리된 코드도 함께 들어 있습니다.

## 학습 내용과 구성

| 위치 | 주요 내용 |
| --- | --- |
| [Week1](Week1), [Week2](Week2) | 입출력, 기본 문법, 함수, `auto`, 구조화된 바인딩과 `vector` |
| [Week3](Week3), [Week4](Week4) | 클래스와 생성자, 헤더·구현 분리, 계산기·계좌·난수 예제 |
| [Week5](Week5), [Week6](Week6), [Week7](Week7) | 객체 배열과 포인터, 동적 메모리, 스마트 포인터 |
| [Week9](Week9), [Week10](Week10) | 객체 전달·복사, 참조, 디폴트 매개변수와 함수 오버로딩 |
| [Week11](Week11), [Week12](Week12) | `friend`, 연산자 오버로딩, 복사·이동 대입 |

## 실행 방법

C++17을 지원하는 컴파일러를 준비하세요. 일부 예제가 C++17의 구조화된 바인딩을 사용합니다. 공통 빌드 설정은 없으므로 실행할 예제의 소스만 선택해 컴파일합니다.

다음은 저장소 루트에서 계좌 예제를 실행하는 명령입니다. Windows PowerShell과 `g++` 기준입니다.

```powershell
g++ -std=c++17 Week4/Week4_Account/accountmain.cpp Week4/Week4_Account/account.cpp -o account.exe
./account.exe
```

메뉴에서 `1`은 입금, `2`는 출금, `3`은 잔액 조회입니다. 시작 잔액은 `50000`입니다.

Visual Studio 등 IDE에서도 같은 예제에 필요한 `.cpp`와 `.h`만 하나의 콘솔 프로젝트에 넣어 실행할 수 있습니다.

## 참고

- 여러 예제에 각각 `main()`이 있으므로 저장소의 모든 `.cpp`를 한 번에 빌드하지 마세요.
- 풀이 모음에는 설명 문장이나 주석 속 프로그램이 포함됩니다. 해당 문제의 코드만 별도 파일에 옮겨 실행해야 하는 경우가 있습니다.
- 일부 원본 파일은 CP949 인코딩입니다. 한글이 깨지면 파일별 인코딩을 확인하세요.
- 수업 당시의 학습 과정을 보존한 저장소로, 전체 예제에 대한 자동 테스트나 일괄 빌드를 제공하지 않습니다.
